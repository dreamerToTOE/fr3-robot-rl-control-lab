# RL00 — MDP & Robot RL Formulation

## Goal
把一个机器人控制问题准确写成 RL 问题。

## Learn
state/observation、action、reward、transition、episode、discount、policy。

## Engineering
选择一个最小 Pendulum 示例，并为后续 FR3 Reach 写一份 MDP card。

## Deliverables
- `docs/RL00_MDP_CARD.md`
- state/action/reward/termination 四张小图或 Mermaid
- 5 个自测问题

## PASS
用户能独立回答：给一个机械臂任务，哪些量放 observation，action 选什么层级，reward 与 benchmark 有什么区别。
